# Dictate for iPhone (work in progress)

A test app that records from the Action Button and shows a black and white bar in the Dynamic Island.

**Status:** it has not been compiled or run yet. It saves the recording on the iPhone. It does not connect to the Mac or insert text yet.

## Try it

1. Open `HandyDictate.xcodeproj` in Xcode.
2. Set your team for both targets in **Signing & Capabilities**.
3. Run it on an iPhone with iOS 18 or later.
4. Tap **Allow microphone**.
5. Set **Settings > Action Button > Shortcut** to **Start or Stop Dictation**.
